P2 首页链接未用 ref shortcode，无法适配多语言/检测死链

content/zh/_index.md · content/en/_index.md

中英文首页均用裸 markdown 链接 /tools/xxx/。在 defaultContentLanguageInSubdir=true 下，英文页的这类绝对路径不会自动加 /en/ 前缀，Hugo 也无法在构建期检测死链。

修复：改用 {{< ref "tools/xxx.md" >}} 或 relref，由 Hugo 解析路径、自动加语言前缀并在链接失效时报错。

P2 header.html 语言切换硬编码路径

修复：改用 {{ .RelPermalink | absLangURL }} 或保留标准 AllTranslations 循环分支，让 Hugo 自动生成正确语言链接。
